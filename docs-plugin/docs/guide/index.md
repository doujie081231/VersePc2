# 介绍

VersePC2 提供了一套轻量的插件机制，允许第三方开发者向启动器扩展能力。插件以 **zip 包** 形式分发，内含一份 `plugin.json` 清单；用户在**插件市场**中浏览、下载并安装。

## 插件是什么

一个插件就是一个符合约定的目录（最终会解压到 `data/plugins/<id>/`），核心是一份 `plugin.json`。安装、列表、卸载都由启动器统一管理，你无需关心数据落盘细节。

## 你能做什么

- **功能插件**（`category: function`）— 新增独立页面、向现有页面插入卡片，或通过 IPC/事件给内置功能扩展能力。
- **个性化插件**（`category: personalize`）— 用 Vue 模板并配合 `main` 脚本对**整个启动器前端**做自定义：主题、外观、宠物挂件等。

## 插件市场

启动器的插件市场读取一个远程索引 `index.json`（默认仓库为 `doujie081231/verseplugin`）。只要你的插件包能下载、索引能解析，它就会出现在市场里。
