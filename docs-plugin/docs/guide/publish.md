# 提交审核与开源

自制插件不能直接放到插件市场，需要先提交审核，通过后由官方上传。上传即表示同意以 **GPLv3** 协议开源。

## 提交地址

将你的插件包通过邮件发送至官方提交审核：

```
verselauncher@verselauncher.cn
```

## 需要提交的内容

1. **插件包 zip**（内含 `plugin.json`，规则见 [plugin.json](plugin-json)）。
2. **说明文本**，包含：
   - 插件 `id` 与 `name`
   - 类型：`功能插件`（新增页面 / 插入卡片）或 `个性化插件`
   - 功能简述
   - 若为"新增页面"类型：**附上 SVG 图标**（用作侧边栏按钮图标）
   - 依赖/兼容要求

## 审核与发布流程

```text
打包 zip + 说明  →  邮件发送至 verselauncher@verselauncher.cn  →  官方审核
   →  通过：官方上传至 verseplugin 仓库 + 更新 index.json  →  所有用户可见可安装
   →  不通过：邮件回复修改意见，修改后重新提交
```

## 开源协议：GPLv3

- 插件包上传到插件仓库即表明以 **GNU GPL v3** 协议开源。
- 采用 GPLv3 意味着：他人可以在相同协议下复制、修改、再分发你的插件，并需保留来源声明。
- 交付前，请确保你的插件代码可以按 GPLv3 授权（不包含闭源/有版权争议的素材）。

## 版本更新

- 修改 `plugin.json` 的 `version`，重新打包，再次走邮件提交审核。
- 审核通过后官方更新市场里的版本与哈希，已安装用户会看到"更新"按钮。
