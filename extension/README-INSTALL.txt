VersePC2 浏览器扩展 — 手动安装说明

【为什么需要手动装】
浏览器出于安全限制，不允许网页/程序静默安装扩展。
VersePC2 已经帮你做好了 3 件事：
  1. 扩展文件已释放到本文件所在目录
  2. 原生通信宿主已注册
  3. 浏览器的「外部扩展」注册表已写入

剩下最后一步——在浏览器里启用它。三种方式任选：

【方式一：重启浏览器（最省事）】
Edge / Chrome 完全退出后重新打开，通常会提示「已添加扩展，是否启用」，
点「启用」即可。

【方式二：手动加载解压目录（最可靠）】
1. 地址栏输入：
     Edge    → edge://extensions/
     Chrome  → chrome://extensions/
2. 打开「开发人员模式」（Edge 在左下角，Chrome 在右上角）
3. 点「加载解压缩的扩展」/「加载已解压的扩展程序」
4. 选择本文件所在的这个文件夹（路径已复制到你的剪贴板）

【方式三：用启动器带参数启动】
在 VersePC2 里点「一键安装」时，如果浏览器当时没在运行，
启动器会带 --load-extension 参数把它拉起来，扩展会立即生效。

【验证是否装好】
回到 VersePC2 → 设置 → 其他设置 → 浏览器下载接管 → 点「重新检测」。
状态灯变绿、显示「已就绪」即成功。

宿主名：cc.versepc.download_bridge
